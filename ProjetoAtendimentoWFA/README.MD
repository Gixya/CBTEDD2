# Projeto Atendimento

Projeto desenvolvido em C# para a disciplina de Estrutura de Dados 2 (CBTEDD2).

Uma central de atendimento gera senhas para os clientes e distribui o atendimento entre os guichês disponíveis.
O sistema deve manter o controle da fila de espera (senhas geradas) e do histórico de atendimentos realizados em cada guichê.

## Tecnologias
- C#
- .NET
- Programação Orientada a Objetos (POO)
