# Projeto Gerenciador de Projetos

Projeto desenvolvido em C# para a disciplina de Estrutura de Dados 2 (CBTEDD2).

O sistema permite cadastrar projetos, gerenciar tarefas, alterar status, filtrar por prioridade e consultar resumos.

## Tecnologias
- C#
- .NET
- Aplicação Console
- Programação Orientada a Objetos (POO)

## Como executar
Abra o projeto no Visual Studio e execute com `F5`.
