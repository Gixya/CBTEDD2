# Projeto Agenda

Projeto desenvolvido em C# para a disciplina de Estrutura de Dados 2 (CBTEDD2).

O sistema permite cadastrar, pesquisar, alterar, remover e listar contatos, armazenando informações como nome, email, data de nascimento e telefones.

## Tecnologias

* C#
* .NET
* Aplicação Console
* Programação Orientada a Objetos (POO)

## Como executar

Abra o projeto no Visual Studio e execute com `F5`.
