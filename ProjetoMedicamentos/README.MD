# Projeto Medicamentos

Projeto desenvolvido em C# 

O sistema permite cadastrar medicamentos, controlar lotes, registrar compras e realizar vendas priorizando os lotes com vencimento mais próximo.

## Tecnologias
- C#
- .NET
- Aplicação Console
- Filas (Queue)
- Listas (List)

## Como executar
Abra o projeto no Visual Studio e execute com `F5`.
