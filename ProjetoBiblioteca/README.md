Projeto Biblioteca

Projeto desenvolvido em C# para a disciplina de Estrutura de Dados 2 (CBTEDD2).

O sistema permite cadastrar e pesquisar livros, adicionar exemplares, registrar empréstimos e devoluções.

Tecnologias:

- C#
- .NET
- Aplicação Console
- Programação Orientada a Objetos (POO)

Como executar: Abra o projeto no Visual Studio e execute com F5.
