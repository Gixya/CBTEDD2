# Projeto Controle de Acessos

Projeto desenvolvido em C# para a disciplina de Estrutura de Dados 2 (CBTEDD2).

O sistema permite cadastrar usuários e ambientes, controlar permissões de acesso e registrar tentativas autorizadas e negadas.

## Funcionalidades
- Cadastro de usuários e ambientes
- Concessão e revogação de permissões
- Registro de acessos
- Consulta de logs
- Limite de 100 registros por ambiente

## Tecnologias
- C#
- .NET
- Aplicação Console
- Listas (List)
- Filas (Queue)

## Como executar
Abra o projeto no Visual Studio e execute com `F5`.
