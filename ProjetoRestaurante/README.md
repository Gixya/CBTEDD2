# Projeto Restaurante

Projeto desenvolvido em C# para a disciplina de Estrutura de Dados 2 (CBTEDD2).

O sistema simula o funcionamento de um restaurante, permitindo cadastrar pedidos, adicionar e remover itens, consultar pedidos, cancelar pedidos e listar os pedidos do dia.

## Funcionalidades

* Criar novo pedido
* Adicionar item ao pedido
* Remover item do pedido
* Consultar pedido
* Cancelar pedido
* Listar todos os pedidos
* Calcular o valor total de cada pedido
* Calcular a soma geral dos pedidos do dia

## Estrutura

* `Program.cs` - inicia o programa
* `Item.cs` - representa os itens do cardápio
* `Pedido.cs` - representa os pedidos
* `Restaurante.cs` - controla os pedidos
* `View.cs` - exibe o menu e mensagens
* `Controller.cs` - controla as funcionalidades do sistema

## Limites

* Até 50 pedidos
* Até 10 itens por pedido

## Como executar

Abra o projeto no Visual Studio e execute o programa pelo botão **Iniciar** ou pressione `F5`.
